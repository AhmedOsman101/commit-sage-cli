# 0015 — Bun-native APIs first, `node:*` only where Bun has none

All runtime calls in the seam modules (`command.ts`, `fileSystem.ts`, `spinner.ts`, `logger.ts`, commit preview, env/args) prefer a `Bun.*` API wherever one exists (`Bun.file().text()`, `Bun.write`, `Bun.spawn` with native `timeout`, `Bun.markdown.ansi()`, `Bun.color`/`stripANSI`/`stringWidth`), and use `node:*` only where Bun offers no native equivalent (directory ops, signals, TTY checks, `mkdir`/`stat`). Chosen because the maintainer wants smaller compiled binaries and Bun-native calls bundle cheapest; the seam modules keep the trade cheap to reverse since the rest of `src/` stays runtime-free. Rejected the `node:*`-everywhere alternative (maximal portability) because it forfeits the size motive and Bun already covers the hot paths.
