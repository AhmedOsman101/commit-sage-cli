# 0016 — Keep Cliffy on Bun via JSR, drop charmd for `Bun.markdown.ansi()`

`@cliffy/command`, `flags`, `table`, and `prompt` stay, installed through the JSR npm-compatibility layer (`npm:@jsr/cliffy__*@1.3.1`, `@jsr` scope in `.npmrc`), because Cliffy 1.x officially supports Bun from the same source and the 1:1 API fit preserves every subcommand, typed option, `Secret` prompt, `Checkbox` search, and the exit-130 abort path untouched. Rejected the `commander` + `@inquirer/prompts` rewrite: same behavior for a full CLI rewrite with no proven gain. `@littletof/charmd` is dropped the other way — Deno/Node-only badge, three years stale, self-declared gaps — replaced by zero-dependency `Bun.markdown.ansi()` for the commit preview, with the subject kept bold outside the renderer (probed: `ansi()` mangles pre-styled ANSI input). Record compiled binary size per target before and after every such swap.
