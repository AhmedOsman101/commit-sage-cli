# 0007 — Providers as data literals over one shared runner

Each AI provider is a `defineProvider()` literal (client factory, provider-options mapper, apiType) executed by one shared `ModelService.run()`, instead of one class file per provider. The audit counted 362 duplicated lines (6.6%) across the provider files. Chosen because every new preset (groq now, gateways later) would otherwise copy another ~50-line class, and the duplication had already produced drift (per-file baseUrl reads bypassing the per-value chain). Kept: the `ModelService` public surface (`getGenerationOptions`, `getApiType`, `getProviderApiKey`, retry wiring) so call sites do not change; bespoke wire formats (anthropic, google, ollama, openai responses branch, openrouter headers) stay as explicit adapter variants rather than being forced through the generic path.
