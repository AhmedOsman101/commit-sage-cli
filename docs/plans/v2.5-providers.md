# v2.5.0 — Provider completion

Theme: one new preset, any-gateway dispatch, less duplication, honest knobs.
Status: post-grill. Grill protocol: `grill-with-docs` rounds 1-2, 2026-10-05.

## Goal and user story

As a user, I want Groq as a ready-made preset, any OpenAI-compatible gateway
addressable by name without waiting for a release, fewer dependency surprises
in install, and reasoning knobs that fail loudly at config time instead of
with a provider 400 at generation time.

## Exact CLI surface

No new commands or flags. New config keys only (table below) plus one new
`model` identity shape: `<user-named-provider>/<model>` (e.g.
`omniroute/kimi-k2`) resolves through `providers.omniroute`. Exit codes
unchanged. Non-TTY unchanged: gateway dispatch needs no prompts.

## Config deltas

| Key | Type | Default | Notes |
|---|---|---|---|
| `providers.groq.baseUrl` | string (uri) | `"https://api.groq.com/openai/v1"` | new preset entry |
| `providers.groq.apiKey` | string | `"$GROQ_API_KEY"` | `$`-prefix reads env, else literal |
| `providers.groq.models` | map | `{}` | per-model presets, same shape as other providers |
| `providers.<name>.baseUrl` | string (uri) | — | already exists; now sufficient (with `apiType`) to dispatch unknown names |
| `providers.<name>.apiType` | enum | inherits `openai-chat` | already exists; `openai-chat` / `openai-responses` / `anthropic` select the generic adapter |
| `providers.<name>.headers` | map string→string | `{}` | **new** escape hatch (attribution or gateway auth headers) |
| `providers.<name>.useApiKey` | boolean | `true` | **new**; `false` (or local host without key) sends no auth header |
| `providers.gemini.thinkingBudget` | number | `0` | **new**; 0 off, -1 model decides, Gemini 2.5 only, Pro floor 128 |
| `providers.gemini.thinkingLevel` | enum `minimal\|low\|medium\|high` | `"low"` | **new**; Gemini 3.x only, cannot be disabled |

Additive only. No migration. `SUPPORTED_PROVIDERS` gains `"groq"`.
`SUPPORTED_REASONING_LEVELS` keeps its members; enforcement moves to
per-provider validation (warn + remap) so unknown gateways keep full
passthrough. `mask schema build` regenerates; `mask schema check` green.

### Behavior changes

- `model: "groq/<id>"` works out of the box; default Groq model
  `openai/gpt-oss-120b` is a Groq-hosted id, not ours. README recommends
  `qwen/qwen3-8b-27b` as the lighter alternative with the same free-tier
  limits.
- Unknown provider name + `providers.<name>.baseUrl` set ⇒ generic
  OpenAI-chat (or responses/anthropic per `apiType`) dispatch. Unknown name
  without `baseUrl` ⇒ configuration error naming the missing key (exit 1),
  not a dispatch crash.
- `useApiKey: false` ⇒ no `Authorization` header. Local hosts
  (`localhost`, `*.local`, `*.internal`) without a key ⇒ no header either
  (extends the existing `LOCAL_NO_AUTH` behavior to gateways).
- Reasoning: known providers validate against their subset at load
  (out-of-range ⇒ warn + nearest valid; never a runtime 400 from our side).
  `true` keeps meaning "provider default with reasoning on" and now omits
  temperature without forcing a level. Unknown providers passthrough any
  inherited level verbatim.
- Gemini family gating mirrors the extension: `thinkingLevel` sent only for
  `gemini-3*`, `thinkingBudget` only for `gemini-2.5*` (Pro floor 128),
  neither for 2.0/Gemma (silently omitted, matching upstream).

## File-level implementation sketch

Phased inside the milestone (refactor first, presets as literals):

1. **Adapter seam** (`src/services/providerAdapter.ts`, new): `ProviderAdapter`
   (`createModel(ctx)`, `providerOptions?(reasoning)`,
   `factoryOptions?(ctx)`, `apiType?(ctx)`), `defineProvider()` helper,
   `adapterRegistry`. `ModelService.run()` shared shell: resolve
   apiKey/baseUrl/apiType/reasoning/timeoutMs via `resolveProviderValue`,
   single `wrapLanguageModel(think)` + `generateText`, one retry callback.
   Keep `getGenerationOptions` / `getApiType` / `getProviderApiKey` /
   `handleGenerationError` signatures.
2. **Migrate 11** `src/services/providers/*.ts` to literals behind the
   registry, family by family (debug-template trio, minimal quad, rest).
   Move the 4 reasoning getters verbatim onto adapters. Fix the two
   baseUrl bypasses (`openai.ts:24`, `ollama.ts:23-33`) onto
   `resolveProviderValue(provider, modelId, "baseUrl")`. Delete dead
   `handleApiError` / `extractCommitMessage` stubs if still present.
3. **Consolidate deps**: `deepseek`, `mistral`, `moonshotai`, `xai`,
   `minimax` (+ `vercel-minimax-ai-provider`), `zai` onto
   `createOpenAI`-with-baseUrl inside their literals. Keep `anthropic`,
   `google`, `ollama-ai-provider-v2`, `openai`, `openrouter` explicit
   (bespoke wire / responses branch / attribution headers). Drop removed
   imports from `deno.json` + lockfile.
4. **Generic dispatch** (`src/services/model.ts` or adapter module):
   `getAdapter(provider, config)` — known literal wins; else entry with
   `baseUrl` ⇒ `genericAdapterFor(entry.apiType)`; else
   `ConfigurationError` naming `providers.<name>.baseUrl`. `headers` merge
   into the client options.
5. **`groq` literal**: `createOpenAI({ apiKey, baseURL })` +
   `getOpenAIProviderOptions`, `.chat(modelId)`; `DEFAULT_CONFIG`
   entry + `SUPPORTED_PROVIDERS` + registry + docs.
6. **Gemini thinking**: resolve `thinkingBudget`/`thinkingLevel` in the
   Gemini literal path with family gating; wire into
   `{ google: { thinkingConfig } }` alongside the existing `thinkingLevel`
   mapping. Reasoning subset validation per known provider (table in code,
   warn + remap).

## Test plan

- Unit: adapter registry resolves all 12 known names; unknown + baseUrl ⇒
  generic chat adapter; unknown without baseUrl ⇒ error names the key;
  `useApiKey: false` ⇒ no auth header; local host without key ⇒ no header;
  reasoning validation matrix (each known provider × in-range/out-of-range);
  unknown provider passes `xhigh`/`none` through verbatim; Gemini family
  gating (3.x level only, 2.5 budget only, Pro floor 128, 2.0/Gemma omit).
- Integration: `generate --model groq/openai-gpt-oss-120b` (key-gated,
  network; smoke only); `generate --model omniroute/<id>` against a local
  stub gateway (tests generic dispatch + headers + no-auth).
- Regression: byte-identical prompts for all 11 existing providers before
  and after the adapter migration (fixture diffs); `mask typecheck` per
  family; `deno check` after dep removal proves no dangling imports.
- Schema: `mask schema check` green; new keys validate, `headers` map
  accepts string pairs, `thinkingBudget` accepts -1.
